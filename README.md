# Career Track

![Career Track](public/preview.png)

就職活動に必要な企業情報・応募状況・面接予定・企業評価をまとめて管理するためのWebアプリです。

複数の求人媒体から応募すると情報が分散しやすく、「次に何をすべきか」「どの企業が選考中か」が分かりにくくなる課題を解消するために制作しました。

企業情報を登録するだけでなく、選考状況ごとの一覧表示、検索・絞り込み・並べ替え、応募予定の管理、企業との相性評価まで一つの画面で確認できます。

## 主な機能

### 企業情報管理

- 企業名、求人名、応募媒体などの登録
- 応募状況の管理
- 企業情報の編集・削除
- 重複登録の検出
- アーカイブ・復元

### 選考状況管理

企業を以下のタブに分類して表示できます。

- すべて
- 選考中
- 結果待ち
- 面接予定
- 内定
- 不採用
- アーカイブ

各タブには対象企業の件数が表示されます。

「選考中」は活動中企業の広いグループとして扱い、「面接予定」「結果待ち」はその一部を確認しやすくするためのタブとして設計しています。

### 検索・絞り込み

- 企業名
- 求人名
- 応募媒体
- メモ
- 応募管理メモ
- 選考状況

検索文字列は全角・半角や大文字・小文字の違いを吸収して検索します。

応募媒体と応募状況は、複数選択による絞り込みが可能です。

### 並べ替え

- 選考優先度順
- 総合評価が高い順
- 総合評価が低い順
- 応募日が新しい順
- 応募日が古い順
- 登録日が新しい順
- 登録日が古い順
- 最終更新日が新しい順
- 企業名順

企業の固定表示順は、日常的な確認のしやすさを考慮して以下の順番にしています。

1. 未応募
2. 応募準備中
3. 選考中
4. 内定
5. 保留
6. 辞退
7. 求人終了
8. 不採用

選択した並べ替え条件は、各状況グループの中で適用されます。

### 応募管理

- 次回予定日時
- 応募・提出期限
- 面接予定
- 応募に関するメモ

企業ごとに、次に必要な行動や予定を記録できます。

### 企業評価

希望する働き方や条件と、企業情報を比較して評価します。

評価は生成AIによる自動判定ではなく、あらかじめ設定したルールに基づいて算出しています。

評価項目や加点・減点の理由を表示し、利用者が判断材料を確認できるように設計しました。

必要に応じて手動で点数を調整できます。

### レスポンシブ対応

- PCではテーブル形式
- スマートフォンではカード形式
- タブレット・スマートフォン向けのタブレイアウト
- モバイル用の企業追加ボタン

## 制作背景

就職活動では、求人サイト、企業メール、面接予定、応募書類などの情報が複数の場所に分散します。

応募企業が増えるにつれて、次のような課題を感じました。

- どの企業へ応募したか分からなくなる
- 面接や提出期限を見落としそうになる
- 不採用企業が一覧に残り、確認したい企業が埋もれる
- 求人媒体ごとに情報が分かれている
- 応募先を比較するための判断基準が曖昧になる

これらを一つのアプリで整理し、「今どの企業を確認すべきか」が分かる状態を目指して制作しました。

## 工夫した点

### 実際の利用に合わせて改善

当初は企業情報を登録する一覧画面として制作しましたが、実際に就職活動で使用しながら改善を重ねました。

企業数が増えたことで必要になった機能として、以下を追加しています。

- リアルタイム検索
- 応募媒体・状況による絞り込み
- 登録日・応募日・更新日による並べ替え
- 選考状況ごとのタブ
- アーカイブ機能
- 重複登録の確認
- モバイル表示

### データの一貫性

選考状況は `applicationStatus` を基準として一元管理しています。

一覧画面、タブ、絞り込み、並べ替えで異なる判定を持たせず、共通のステータス定義を使用することで、表示の不整合を防いでいます。

### 日付処理

日付の保存・表示では、タイムゾーンによる日付のずれが起きないように処理しています。

### 後方互換性

機能追加前に保存されたデータも引き続き利用できるようにし、既存データを一括で書き換えずに読み込める設計にしています。

### 説明可能な評価ロジック

企業評価では、生成AIが理由の分からない点数を出すのではなく、ルールベースで評価しています。

点数だけでなく、どの条件によって加点・減点されたかを表示することで、最終的な判断は利用者自身が行えるようにしています。

## データ保存について

現在のバージョンでは、登録したデータをブラウザのLocalStorageへ保存しています。

そのため、データは利用している端末とブラウザ内に保存され、別の端末とは同期されません。

今後はGoogleログインとクラウドデータベースを導入し、複数端末から同じデータを利用できるようにする予定です。

- 対応が必要な企業を表示する画面

## セットアップ

### 1. リポジトリをクローン

```bash
git clone https://github.com/ユーザー名/career-track.git
```

```bash
cd career-track
```

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```
